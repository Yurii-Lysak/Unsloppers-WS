Header keeps only contextual actions:
User identity lives in one place — the bottom of the sidebar. Clicking the chip opens the account menu: a header with the email, then "My profile" (→ the user's own EmployeeProfilePage), "Notification preferences" (→ a modal with toggles, see Modals), and, below a divider, "Sign out". The header carries only a contextual action (notifications) — no duplicated name.

Destructive actions — a distinct style, not "outline" lumped in with neutral actions
Reject / Reverse / End pair / Delete view currently all share one neutral outline style in the code. .btn-outline-danger clearly signals "this action has consequences" while staying lighter-weight than the filled .btn-destructive (reserved for irreversible deletion).
